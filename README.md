## Advanced Sales & Customer Analytics

### Objective
Analyze sales and customer data to identify profitability drivers, high-value customers, and retention trends.

### Tools Used
- Python
- Pandas, NumPy
- Matplotlib

### Key Analysis
- Data cleaning using statistical and business-rule-based methods
- Product-level profitability analysis
- Customer segmentation and repeat behavior analysis
- Customer Lifetime Value (CLV) calculation
- Cohort-based retention analysis

### Business Insights
- A small percentage of customers contribute the majority of profits
- Certain products generate high revenue but low margins
- Retention drops after first purchase, indicating onboarding opportunities
